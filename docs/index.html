How it works

No server, no paid API calls. A Claude Code scheduled session does the work, emails the digest, and commits this dashboard's data.

  1. Step 1 · Trigger Scheduled Claude Code session Daily at 6:00 AM Central. Reads config.yaml and the 30-day memory.
  2. Step 2 · Five research agents in parallel
  3. Step 3 · Editor agent Dedupe, merge, rank Drops anything already sent, merges duplicate stories, ranks by severity and credibility, writes the summary.
  4. Step 4 · Outputs
    Email digestSent through Gmail SMTP.
    Structured JSONChecked by a no-LLM validator, then committed.
    This dashboardStatic page on GitHub Pages.
